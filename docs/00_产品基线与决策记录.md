# 产品基线与决策记录

版本：V0.7  
状态：规划基线  
最后更新：2026-07-31

## 1. 产品定义

本产品的长期定位是一套“专业逆向标注与能力训练平台的公共底座＋可独立演进的专业域”。公共底座承载身份、作业、多人答案、评审、审定、版本、审计、金标准和数据交换；广告视频创意是首个专业域。

当前MVP仍通过“寻找优秀作品—提交视频—逐镜反写—结构化标注—团队评价—形成共识—反馈奖励”的过程，训练个人和团队的视频创意分析能力。它不是单纯的视频收藏夹，也不是单纯的标注外包平台。案例收集、个人学习和团队数据沉淀是同一条业务链路。

未来可以接入地产策略报告等第二专业域，但当前不预设其标注对象、字段和评价标准，也不因平台升格暂停广告视频专业域。

## 2. 统一术语

| 术语 | 定义 |
|---|---|
| 反写 | 从视频成片逆向还原逐镜脚本，并解释其创意构成和故事组织 |
| 逆向工程 | “反写”的同义业务表达 |
| 专业域 | 具有独立逆向对象、标注标准、答案结构、评分标准和专业词表的业务模块 |
| 平台公共底座 | 为所有专业域共用的身份、作业、提交、评审、审定、版本、审计、金标准和导出交换能力 |
| 逆向对象 | 平台统一管理的待分析对象；在广告域中表现为视频案例 |
| 案例 | 一条进入团队案例库的视频作品及其来源、标注和评价 |
| 素材贡献 | 成员通过直接上传视频文件向案例库提交作品 |
| 个人标注 | 某一成员独立完成的一套逐镜脚本及 9＋10 结构化标注 |
| 共识标注 | 团队在比较多份个人标注后形成的独立结论 |
| 管理员精修版 | 管理员在保留个人原始提交的前提下形成的校订版本 |
| 标注体系 | 字段、问题、选择规则、选项和说明的版本化集合 |
| 作业评分 | 按版本化的100分量表，对一份反写作业的核心判断、逐镜还原、结构化标注、镜头点评和全篇总结进行批阅 |
| 创意奖级投票 | 成员对视频作品本身选择大奖级、金奖级、银奖级、铜奖级或入围级 |
| 创意综合分 | 由视频奖级投票换算得到的作品分数，不等同于任何个人作业分 |
| 评选活动 | 管理员选择若干份已提交作业，指定参与范围和评分规则后发起的集中评价 |
| 管理员校订 | 管理员对视频信息、作业分析、评分有效性或共识数据进行有审计记录的质量处理 |
| 评审轮次 | 一次评选活动内具有独立候选、评分任务、时间和晋级规则的阶段 |
| 共创贡献 | 成员对某个镜头、字段或整体分析追加的新观点、标签建议、依据或文字 |
| 优秀Mark | 管理员对高质量标注或共创贡献添加的质量标记 |
| 最佳整体标注 | 管理员从个人标注、共创贡献、精修和共识中组装并发布的最终优质方案 |
| 金标准 | 经过明确审定、绑定专业域和版本、保留原始来源及修订理由，可用于训练或评估的高质量答案版本 |
| 准确度 | 个人提交与已发布共识的结构化比较结果，不等同于人气 |
| 热度 | 浏览、收藏、评价、讨论等行为形成的活跃度指标 |

当前不将“仿写”列为 MVP 主流程。基于案例生成原创脚本或仿写训练属于后续智能化阶段。

## 3. 权威来源

产品规则的优先级如下：

1. 用户明确确认的最新产品决策；
2. `视频广告创意反向标注训练空白表_V0.2.xlsx`，负责广告视频专业字段及标注规则；
3. 《平台公共底座与专业域架构》A0.1，负责公共能力与专业域边界；
4. 本规划包中的其他产品与工程文档；
5. 后续研发实现说明。

当文档与 V0.2 广告标注定义冲突时，以 V0.2 为准，并通过新文档版本修正，不能由研发自行解释。V0.2不用于推导其他专业域字段，也不决定平台公共对象边界。

## 4. 已确认的产品原则

### P-001 以个人用户为基本主体

上传、反写、标注、评价、评分、收藏和奖励都必须绑定真实用户。系统需要保留个人训练轨迹，而不是只保留最终团队结果。

成员使用企业微信身份登录。首发只有一个公司工作空间，成员同步或保存企业微信部门标签。

### P-002 个人学习与集体学习并存

个人通过完成任务获得训练；团队通过案例广场、公开标注、百分制批改和共识共享学习成果。

### P-003 每个人都能贡献素材

成员自行寻找作品并直接上传视频文件。第一版不建设网址解析和网址转可观看能力。

视频上传在业务上不限制格式、大小、时长和下载。工程实现仍需完成安全扫描、存储保护、兼容性检测和必要转码；无法直接播放的源格式应保留原文件并生成兼容播放版本。

### P-004 内部公开学习

这是内部使用网站，只有一个公司空间，不设敏感项目。公司成员可以查看全部视频案例、已提交个人作业、标签、评分和讨论。

个人作业草稿提交前仅作者和管理员可见；提交后向公司全员公开。产品鼓励成员阅读已提交作业、相互评分和评选。

### P-005 原始作业保留

成员不能修改其他人的作业。管理员可以校订，但必须形成独立、有审计记录的管理员精修版；个人原始提交和历史修订始终保留。

个人提交是学习档案，共识是团队结论。二者必须独立保存并可追溯。

### P-006 当前体系为 9＋10

创意构成采用 A1–A9；故事组织采用 B1–B10。所有新标注绑定 V0.2 或其后续正式版本。

### P-007 删除进入回收站

案例、任务、草稿、评价和配置默认软删除。恢复、永久删除和保留期限由权限及政策控制。

### P-008 百分制作业评分

每份作业满分100分：

- 商业意图3分；
- 创意母题5分；
- 故事梗概4分；
- 创意思维链10分；
- 逐镜脚本还原35分，作为核心大题；
- 创意构成A1–A9共9分；
- 故事组织B1–B10共10分；
- 镜头创意点评20分；
- 全篇创意总结4分。

19项标注依据不计分，也不作为为了得分而设置的必填项。

个人评分、同行均分、管理员批阅分和发布分分别保存，不能互相覆盖。

### P-009 奖励基于可解释数据

热度、质量、准确度和贡献量分别计算。奖励结果应能够解释来源，支持撤销和人工校正。

### P-010 AI 后置

MVP 不开发 AI 自动拆镜或自动完成标注。可以预留 AI 数据通道，但不得影响人工闭环交付。

### P-011 单页纵向作业

一条案例的观看、逐镜反写、9＋10标注、总结、阅读他人答案和评分尽量在同一个纵向页面完成。用户通过滚动和页内锚点逐屏填写，不通过多页面跳转割裂思考。

### P-012 导出受控

普通成员可以站内查看内部视频，但不提供原片下载；只有管理员可以导出结构化标注、视频创意投票、作业评分、用户学习和共识数据。

### P-013 极简视频展台

首页采用电影网站或获奖广告展台式呈现。所有视频统一陈列，不建立汽车、食品等行业分类树。首页只保留观看、脚本及创意分析、作业入口、创意奖级、标签搜索和必要的个人入口。

桌面、Pad和手机共享同一信息层级：先看视频，再进入脚本或作业，不把管理后台式的密集导航带到内容首页。

### P-014 视频投票与作业评分分离

视频作品使用五档创意奖级投票，并换算创意综合分进行排位。个人作业继续使用版本化100分量表批改。

两套数据分别存储、分别展示、分别排行，任何页面都不能只写“评分”而不说明是“创意综合分”还是“作业分”。

### P-015 普通用户与管理员双界面

普通用户入口只围绕五类行为：

1. 看片；
2. 查看别人已提交的脚本及创意分析；
3. 练习并提交自己的作业；
4. 搜索视频、标签、用户、公开作业和评论；
5. 给视频投创意奖级，或给别人的作业评分。

管理员能力放入独立后台，不把数据治理、导出和统计控件堆到视频首页。

### P-016 管理员负责数据质量

管理员可以审核、校订和整理数据：

- 视频标题、封面、标签等案例元数据可以直接修正，但保留变更历史；
- 个人作业通过独立管理员校订版修正，原作者版本不被删除或冒名覆盖；
- 无效、恶意或违规评分可以标记无效并从汇总中排除，原评分仍可审计；
- 管理员可以发布示范作业、模板或共识。

### P-017 评选活动与统计

管理员可以勾选若干份已提交作业发起评选活动。活动按轮次冻结候选作业修订和评分规则，系统统计参与率、有效评分人数、加权综合分、中位数、分布、最高分和最低分，并形成可发布结果。

系统只记录业务所需行为事件，不记录无关的键盘输入或侵入式个人轨迹。

### P-018 面向未来的数据导出

只有管理员可以导出。除V0.2 Excel外，导出中心应支持作业评价、评审轮次、共创贡献、优秀Mark、最佳整体标注、管理员校订和共识数据，为未来生成模型范例、评估器范例和模板库提供可追溯数据。

任何导出均保留用户、案例、提交修订、标注体系版本、评分量表版本、管理员校订来源、版权状态和导出目的。

### P-019 平时模式与评审会模式

平时用户以看片、看分析、练习和搜索为主，评分入口保持次要，不制造必须随时打分的压力。

管理员发起创意评审会后，参与者的界面突出：

- 当前轮次；
- 指定互评对象；
- 可自由补评的候选；
- 已评／待评进度；
- 晋级和结果状态。

### P-020 两轮作业评选

第一轮默认使用环形互评：

- 参与者和候选作业按冻结顺序形成一一对应关系；
- 2号评1号、3号评2号，依次循环，1号评最后一名；
- 候选作业少于参与者时，先保证每份候选至少有一名指定评分者，多余参与者进入自由补评池；
- 参与者可以在完成指定任务后自由评分其他非本人作业；
- 多份有效评分按权重汇总，MVP同行评分默认权重均为1。

首轮汇总分超过80分的作业进入第二轮。第二轮由其他成员再次评分，默认避免同一评分者重复评价同一候选。第二轮综合分最高的前两名获得当次最佳作业奖。

### P-021 追加式共创与最佳整体标注

任何成员可以对视频的镜头、A/B字段或整体分析继续追加共创贡献。贡献不能覆盖已有内容，必须记录作者、时间、体系版本和来源位置。

管理员可以为高质量贡献添加优秀Mark，并从个人作业、共创、精修及共识中逐项采纳，形成版本化的最佳整体标注。最佳整体标注默认作为该视频的首选公开分析和高质量导出对象，原始来源仍可追溯。

### P-022 平台公共底座＋专业域

产品采用公共底座与专业域分层。广告视频创意登记为首个专业域 `AD_VIDEO`。未来专业域共用平台流程，但拥有独立的对象、答案结构、标注标准、评分标准和专业词表。

### P-023 公共对象不得绑定视频语义

公共作业、答案、评审、共识、共创、金标准和导出流程统一关联“逆向对象”，不得以 `VideoCase`、镜头、时间码或A/B字段作为平台层前提。

广告视频继续保留视频案例、逐镜脚本、A1–A9、B1–B10及其专用页面和校验逻辑。

### P-024 公共外壳＋强类型专业数据

平台层保存对象身份、任务、答案修订、快照、来源和审计；专业域保存强类型答案。不得为了通用化修改V0.2字段含义，也不建设一张承载所有专业域的万能答案表。

### P-025 四类版本独立管理

平台工作流版本、专业域标注标准版本、评分量表版本和导出／交换协议版本分别管理。所有答案必须绑定专业域标注标准版本；评分和交换还必须绑定各自适用版本。

### P-026 质量数据公共化

原始答案、分歧、修订理由、置信度、管理员精修、团队共识和金标准分别保存。广告域“最佳整体标注”是金标准的一种专业组装与展示方式，不覆盖个人原始答案。

### P-027 评审引擎与广告模板分离

多轮、评委分配、自由补评、权重、晋级和奖项属于平台引擎；环形互评、严格超过80分晋级、第二轮复评和前两名获奖属于 `AD_VIDEO` 当前评选模板。

### P-028 SunOS先定义交换边界

公共平台管理导出任务、版本化交换清单、来源、版权、哈希和幂等信息；专业域生成自己的业务文件。当前只定义与SunOS的交换契约，不建设实时双向同步。

### P-029 广告域优先且不提前设计地产字段

当前继续推进广告视频MVP。地产策略报告的对象、字段、评分和页面等待其标准稳定后设计；当前不建设通用动态表单、跨域评分归一化或专业域切换器。

## 5. MVP 边界

### 包含

- 用户与个人学习档案；
- 训练任务；
- 视频文件直接上传；
- 团队案例广场；
- 视频安全扫描与兼容播放；
- 逐镜反写；
- V0.2 的 9＋10 标注；
- 个人提交及版本记录；
- 百分制互评、字段批注和管理员精修；
- 视频、用户、公开作业和评论搜索；
- 管理员评选活动；
- 两轮评审、环形互评、自由补评和晋级；
- 追加式共创、优秀Mark和最佳整体标注；
- 行为统计、评分汇总和活动统计；
- 多人差异比较与共识发布；
- 基础积分、排行榜和奖励台账；
- Excel 导入导出；
- 权限、审计和回收站。
- 平台公共对象与 `AD_VIDEO` 专业域的基础边界；
- 分歧、修订理由、置信度和金标准来源链；
- 版本化导出／SunOS交换清单边界。

### 不包含

- AI 自动拆镜、转写和结构化标注；
- AI 创作或仿写；
- 面向互联网公众开放的内容社区；
- 视频网址解析和网址转可观看；
- 自动抓取全网视频；
- 绕过来源平台的访问控制；
- 现金结算、兑换商城或复杂财务系统；
- 擅自改写 V0.2 字段定义。
- 地产策略报告的具体标注结构；
- 通用动态表单生成器；
- 跨专业域评分归一化、排行榜和普通用户切换入口；
- SunOS实时双向同步；
- 插件运行时或微服务拆分。

## 6. 成功标准

MVP 成功不是“页面上线”，而是至少一个真实团队可以连续完成：

1. 负责人发布训练要求；
2. 多名成员分别找片并提交；
3. 成员完成逐镜反写和 9＋10 标注；
4. 团队公开浏览并按百分制互相批改；
5. 每周或双周筛选高分作业进行讨论；
6. 管理员对重点作业进行精修；
7. 负责人形成共识；
8. 系统形成个人训练数据、评分、准确度和贡献记录；
9. 管理员能够按 V0.2 结构完整导出数据。
10. 管理员能够选择已提交作业发起评选活动并查看统计结果。
11. 管理员能够完成质量校订，并按生成范例、评估器范例或模板用途导出可追溯数据。
12. 团队能够完成一次首轮互评、严格超过80分晋级、第二轮复评和前两名评奖。
13. 成员能够持续追加共创贡献，管理员能够组装并导出最佳整体标注。
