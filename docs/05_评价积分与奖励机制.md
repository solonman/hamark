# 百分制作业、互评、精修与奖励机制

文档版本：V0.6  
状态：`AD_VIDEO` 专业域评分基线  
评分量表版本：RUBRIC-V0.4

本文件中的百分制题目、视频创意奖级、环形互评、80分晋级和前两名获奖均属于广告视频专业域规则。平台公共层只提供版本化量表、多轮评审、评分分配、权重、晋级、排名和奖项能力，不要求未来专业域采用本量表。

## 1. 作业制定位

系统按照“内部作业网”运行：

1. 负责人每周或每双周发布一次反写作业；
2. 成员自行寻找作品、上传视频并完成反写；
3. 全体成员可以阅读他人的作业；
4. 成员按照统一百分制量表相互批改；
5. 高分和高价值作业进入每周一或双周一讨论；
6. 管理员在有精力时进行专家批阅、校订和精细化打磨；
7. 精修结果沉淀为高质量训练数据。

这是一项“半专家工程”：同行互评负责规模化学习，管理员批阅负责提高关键样本质量。

## 2. 百分制总结构

每份作业满分100分，不再使用“基础50分＋创意展开50分”的旧分组：

| 评分模块 | 分值 | 给分方式 |
|---|---:|---|
| 商业意图 | 3分 | 独立评分 |
| 创意母题 | 5分 | 独立评分 |
| 故事梗概 | 4分 | 独立评分 |
| 创意思维链 | 10分 | 综合评分 |
| 逐镜脚本还原 | 35分 | 核心大题，5大类、7个评分位 |
| 创意构成A1–A9 | 9分 | 每项1分 |
| 故事组织B1–B10 | 10分 | 每项1分 |
| 镜头创意点评 | 20分 | 综合评分 |
| 全篇创意总结 | 4分 | 独立评分 |
| 合计 | 100分 | 所有得分必须展开到评分项 |

广告标题／片名等识别性元数据不计分，但缺失时可以阻止提交。

19项结构化标注的“标注依据”不单独计分，也不作为提交必填项。成员可以自愿填写，批改者也可以在批语中追问依据。

## 3. 核心判断：22分

### 3.1 商业意图：3分

- 3分：商业目标明确、完整，并与作品表达一致；
- 2分：方向基本正确，但目标不够具体；
- 1分：只有模糊判断或与作品连接较弱；
- 0分：未填写或明显错误。

### 3.2 创意母题：5分

- 5分：准确概括核心创意命题，能够统领整片；
- 4分：判断正确，概括略宽或略窄；
- 2–3分：抓到局部创意，但更像情节复述；
- 1分：表述模糊或偏离主导创意；
- 0分：未填写。

### 3.3 故事梗概：4分

- 4分：人物、事件、变化和结局清楚，重点完整；
- 3分：主线完整，有少量遗漏；
- 2分：能够理解大意，但结构或因果不清；
- 1分：片段化复述；
- 0分：未填写。

### 3.4 创意思维链：10分

| 档位 | 描述 |
|---|---|
| 9–10 | 商业问题、洞察、创意机制、叙事与品牌落点的推导完整且有洞察 |
| 7–8 | 逻辑基本完整，关键环节清楚，但深度或证据略弱 |
| 5–6 | 有基本思路，但更多是描述成片，推导不充分 |
| 1–4 | 逻辑零散、结论跳跃或大量复述 |
| 0 | 未填写 |

## 4. 逐镜脚本还原：35分

逐镜脚本还原是本份作业的核心大题，相当于作文。RUBRIC-V0.4按5大类、7个评分位计分：

| 评分项 | 满分 | 关注点 |
|---|---:|---|
| 镜头组分段与顺序（含时间段、镜头组、镜头序号） | 10 | 指向切段落能力：分段是否合理、顺序和时间是否准确、是否漏镜 |
| 景别、机位与运动 | 10 | 指向拍摄实施识别能力 |
| 画面内容／镜头故事 | 10 | 指向画面叙事理解能力 |
| 对白与旁白 | 1 | 逐字还原和角色归属 |
| 字幕与屏幕文案 | 1 | 字幕、文案和品牌落款的逐字还原 |
| 声效 | 1.5 | 环境音、动作音和特殊声效识别 |
| 音乐 | 1.5 | 音乐进入、变化、退出及作用识别 |
| 合计 | 35 | 5大类、7个评分位相加 |

其中“旁白／对白／字幕／文案”合计2分，“声效／音乐”合计3分，但界面分别保留评分位，避免不同创意要素被混为一项。

## 5. 结构化标注：19分

### 5.1 A1–A9：每项1分

每一项按照以下规则给0–1分：

- 1分：按照V0.2规则完成，选择结果和主副关系基本合理；
- 0.5分：完成但存在部分偏差；
- 0分：未填写、违反选择规则或明显错误。

### 5.2 B1–B10：每项1分

给分档位同A类字段。

### 5.3 标注依据不计分

- A1–A9、B1–B10的选择结果本身共计19分；
- “标注依据”不设置分值，不要求为了得分逐项撰写；
- 是否填写依据不影响该字段的1分；
- 批改者如果认为标签不合理，可以直接批注或提出修改建议；
- 管理员精修和共识阶段仍可以补充高质量依据。

## 6. 镜头创意点评：20分

| 评分维度 | 满分 | 关注点 |
|---|---:|---|
| 事实与创意功能区分 | 5 | 是否从“画面发生什么”进一步解释“为什么这样拍” |
| 叙事与情绪作用 | 5 | 是否指出铺垫、推进、转折、情绪等作用 |
| 商业与品牌连接 | 5 | 是否解释镜头如何服务商业意图和品牌进入 |
| 视听洞察与表达 | 5 | 是否识别关键视听机制，表达是否具体、清楚、不重复 |
| 合计 | 20 | 四项相加 |

## 7. 全篇创意总结：4分

- 4分：完整概括创意、故事、文案、视听和商业目标之间的关系；
- 3分：总体判断正确，有少量关系未说明；
- 2分：能够概括主要内容，但缺少综合判断；
- 1分：零散复述；
- 0分：未填写。

## 8. 评分界面与便捷指南

### 8.1 逐项打分位置

- 每个被评分内容旁边直接显示分值输入位和该项满分；
- 逐镜脚本还原显示5大类、7个评分位，分值依次为10、10、10、1、1、1.5、1.5；
- A1–A9、B1–B10分别显示每项一分的评分位；
- 镜头创意点评显示4个五分评分位；
- 不计分的标注依据明确显示“0分／自愿填写”，不制造隐性必填压力；
- 评分输入嵌在对应内容旁，页面顶部只保留总分计数器，末尾保留总体批语与正式提交。

### 8.2 固定总分计数器

页面固定区域始终显示：

- 当前已得总分／100；
- 已评分项数／全部评分项数；
- 尚未评分的项目数量；
- 是否存在超过单项满分、负分或格式错误；
- 正式提交评分前的完整度状态。

任何单项分数变化后，总分立即重算。未评分项与0分必须使用不同状态，避免系统把“还没批”误认为“判为0分”。

### 8.3 悬停显示评分指南

- 鼠标移入“评分指南”区域后立即显示浮窗；
- 鼠标移出该区域后浮窗立即消失；
- 指南显示该项满分、评分档位、判断重点和必要示例；
- 指南必须标明当前评分量表版本；
- 不保留点击锁定状态，鼠标移出后立即消失；
- 指南出现后不遮挡当前输入框和关键作业内容。

## 9. 批改流程

### 9.1 同行批改

- 全体成员可以查看其他人已提交的作业；
- 评分只对一个明确的作业修订生效；
- 未提交草稿仅作者和管理员可见，不能进入同行批改；
- 每位评分者完成全部计分项，并可填写对应批语；
- 每个扣分项可以填写批语；
- 评分者可以推荐该作业进入周会讨论。

普通成员不能修改他人的作业内容。

### 9.2 管理员批阅

管理员可以：

- 对作业重新评分；
- 在字段和镜头位置添加专家批注；
- 建议修改；
- 创建“管理员精修版”；
- 将精修版发布为示范作业或共识候选。

管理员不能物理覆盖个人原始提交。所有改动必须：

- 形成新的精修版本；
- 标明基于哪份个人作业；
- 显示修改前后差异；
- 记录管理员、时间和理由；
- 允许回看原始版本。

### 9.3 周／双周讨论

建议流程：

1. 截止后冻结本期参评作业修订；
2. 系统计算同行均分和推荐数；
3. 按总分、逐镜还原分、镜头创意点评分、推荐数和管理员选择生成候选；
4. 负责人确认讨论名单；
5. 每周一或双周一进行讨论和精细化打磨；
6. 讨论结论形成管理员精修版或团队共识；
7. 发布示范作业并记录奖励。

不能只按平均分自动决定讨论名单，负责人保留选择有争议但值得学习的作业的权利。

## 10. 分数类型

每份作业分别保存：

| 分数 | 定义 |
|---|---|
| 个人评分 | 某一评分者给出的完整100分卷面 |
| 同行均分 | 有效同行评分的平均值 |
| 管理员批阅分 | 管理员给出的专家分 |
| 发布分 | 对外展示、排行或奖励采用的最终确认分 |

默认规则：

- 没有管理员批阅时，同行均分作为暂定分；
- 管理员批阅后，管理员可以确认发布分；
- 系统不默认把同行分和管理员分按不透明权重混合；
- 发布分必须说明来源；
- 分数保留全部计分项、总分和不计分内容的批语。

## 12. 案例热度与评选

作业分数与案例热度分开。

热度信号可以包括：

- 浏览；
- 有效观看；
- 收藏；
- 推荐；
- 批改人数；
- 讨论数量；
- 最近活跃度。

评选维度：

- 总分高；
- 逐镜还原分高；
- 镜头创意点评分高；
- 进步明显；
- 争议大但有学习价值；
- 管理员精选；
- 团队推荐。

## 13. 标注准确度与批改准确度

百分制作业分是人工批阅结果；系统还可以在共识发布后计算结构化准确度。

### 13.1 标注准确度

比较个人A1–A9、B1–B10与已发布共识：

- 完全一致；
- 部分一致；
- 不一致；
- 未作答；
- 合理多解。

### 13.2 批改准确度

系统比较评分者的字段批注与最终精修版／共识：

- 正确指出错误；
- 提出的替代答案被采纳；
- 对合理多解作出有依据的判断；
- 错误扣分或错误建议。

批改准确度单独形成“批改可靠度”，用于识别会批作业的人，不能与作业分混为一谈。

## 14. 积分与奖励

可奖励事件：

| 事件 | 条件 |
|---|---|
| 提交有效案例 | 文件、来源和版权声明完整 |
| 按时完成作业 | 通过提交校验 |
| 获得高分 | 达到当期发布分规则 |
| 入选讨论 | 被负责人确认进入周／双周讨论 |
| 成为示范作业 | 管理员发布精修或示范版本 |
| 完成有效批改 | 完整批改他人作业 |
| 批改准确 | 批改意见被精修版或共识支持 |
| 主持共识 | 按规则完成共识发布 |
| 持续训练 | 连续多个周期完成作业 |

MVP先实现：

- 积分；
- 徽章／荣誉；
- 高分榜和进步榜；
- 示范作业；
- 人工奖励台账。

现金、实物和兑换在线下执行。

## 15. 防刷与公平性

1. 自己给自己的分数不进入同行均分；
2. 每位用户对同一作业修订只有一份有效正式评分；
3. 修改评分保留历史；
4. 评分必须完成必要子项才有效；
5. 评分人数不足时明确显示样本不足；
6. 短时间批量互相给满分需要异常标记；
7. 高分讨论名单由负责人确认，不由算法全自动决定；
8. 管理员批阅与个人同行评分分别展示；
9. 管理员精修不删除个人原稿；
10. 所有奖励可追溯、可撤销。

## 16. MVP验收

- 每份作业能按100分制批改；
- 全部计分项严格合计100分；
- 逐镜脚本还原严格合计35分；
- 创意母题5分、故事梗概4分、创意思维链10分、镜头创意点评20分；
- 19项标注依据不计分且不强制填写；
- 每个分数能展开到子项；
- 页面具有逐项打分位置和固定总分计数器；
- 鼠标移入评分指南区域后立即显示，移出后立即消失；
- 同行评分和管理员评分分别保存；
- 普通成员不能修改他人作业；
- 管理员能够创建精修版但原始提交仍可查看；
- 系统能计算同行均分；
- 高分和推荐作业能进入周／双周讨论候选；
- 共识发布后能计算标注准确度和批改可靠度；
- 分数、精修、发布和奖励均有审计记录。

## 17. 视频创意奖级投票

视频作品本身另设五档创意投票：

| 奖级 | 换算分 |
|---|---:|
| 大奖级 | 100 |
| 金奖级 | 80 |
| 银奖级 | 60 |
| 铜奖级 | 40 |
| 入围级 | 20 |

计算与展示：

- 每名用户对每个视频只有一张有效票；
- 创意综合分为全部有效票换算分的算术平均值；
- 页面显示到小数点后一位，级别判断和排序使用未四舍五入的原始值；
- 90–100展示大奖级，80–89.99展示金奖级，60–79.99展示银奖级，40–59.99展示铜奖级，20–39.99展示入围级；
- 少于3张有效票时显示“票数不足”，不进入正式排名；
- 排名先比较综合分，再比较有效票数，最后比较最近有效投票时间；
- 改票更新当前有效票，历史选择保留审计；
- 首页支持按照当前创意级别筛选。

视频创意综合分评价作品本身；本文件前述100分量表评价某位成员提交的作业。两种分数不合并、不互相换算、不进入同一个榜单。

## 18. 作业评选活动

### 18.1 平时与评审会

- 平时评分是次要动作，用户可以自由评分但不会收到持续强提醒；
- 评审会开始后，系统显示当前轮次、指定任务、自由补评入口和完成进度；
- 只有管理员可以创建、开始、截止和发布评审活动；
- 每个候选绑定不可变作业修订；
- 每一轮分别冻结参与者、候选、评分量表版本和任务关系；
- 候选作者不能给自己的作业产生有效活动分。

### 18.2 首轮环形互评

当参与者与候选作业一一对应时，按冻结后的参与者顺序生成：

```text
2号评1号
3号评2号
……
最后一名评前一名
1号评最后一名
```

一般规则：

- 系统按参与者冻结顺序和候选作者建立环形关系；
- 遇到自己的作业时自动跳到下一名合格评分者；
- 作业少于参与者时，先确保每份作业至少获得一名指定评分者；
- 没有指定任务的多余参与者直接进入自由补评池；
- 完成指定任务的参与者也可以自由评分其他非本人候选；
- 同一用户在同一轮对同一候选只有一份有效评分。

### 18.3 加权汇总

每份候选的轮次综合分：

```text
轮次综合分 = Σ（有效作业分 × 评分权重）÷ Σ评分权重
```

- MVP中普通同行评分权重均为1；
- 数据结构保留权重字段，后续可以引入经过批准的评分者可靠度权重；
- 自评分、被管理员判定无效的评分和截止后未提交的评分不进入汇总；
- 页面显示到小数点后一位，晋级和排序使用未四舍五入原始值；
- 样本数、权重合计和计算版本必须可查看。

### 18.4 第二轮晋级和获奖

- 首轮综合分严格大于80分的候选晋级；恰好80分不晋级；
- 第二轮候选绑定首轮晋级时的作业修订；
- 系统优先分配未在首轮评价过该候选的其他评分者；
- 第二轮每份候选目标至少3名有效评分者；
- 如果合格参与者不足，系统提示管理员确认例外，不静默降低要求；
- 第二轮仍允许完成指定任务后自由补评；
- 第二轮综合分最高的前两名获得当次最佳作业奖；
- 候选不足两份时按实际数量颁奖；
- 第二名边界完全同分时，先比较有效评分人数，再比较中位数；仍相同时由管理员确认。

### 18.5 活动统计

每份候选至少统计：

- 有效评分人数；
- 平均分；
- 中位数；
- 最高分和最低分；
- 标准差；
- 分数区间分布；
- 完成评分人数和未完成人数；
- 当前排名。

活动整体统计首轮指定互评完成率、自由补评次数、晋级数量、第二轮覆盖率、参与率、完成率和候选间分数差异。

### 18.6 结果审核

- 活动截止后先进入“待发布结果”；
- 管理员可以检查异常评分；
- 无效、恶意或违规评分可以被排除出汇总；
- 排除必须记录评分、管理员、理由和处理前后统计；
- 原评分不物理删除；
- 重算后形成新的活动结果快照；
- 管理员确认后向参与范围发布结果。

评选活动统计不能与视频创意奖级投票混用：前者比较个人作业质量，后者评价视频作品本身。

## 19. 共创、优秀Mark与最佳整体标注

### 19.1 追加式共创

成员可以对以下位置不断追加内容：

- 某一镜头；
- 某一A/B字段；
- 创意思维链、镜头点评或全篇总结；
- 整个视频的补充分析。

每条贡献可以包含文字、候选标签、依据、时间码和镜头引用。贡献只追加，不覆盖个人作业、共识或他人贡献。

### 19.2 优秀Mark

管理员可以对个人标注、共创贡献、管理员精修或共识中的具体内容添加优秀Mark。Mark包含：

- 标记对象和位置；
- 优秀原因；
- 标记管理员；
- 时间；
- 适用体系版本；
- 是否推荐进入最佳整体标注。

优秀Mark是质量判断，不修改被标记内容本身。

### 19.3 最佳整体标注

管理员可以逐镜头、逐字段采纳来源，组装最佳整体标注：

- 每一项记录来源对象、作者和修订；
- 允许管理员在采纳后进一步校订，但必须记录差异；
- 发布后生成不可变快照；
- 新修改产生新版本；
- 已发布版本作为视频默认首选分析；
- 原个人作业、共创贡献、精修和共识仍可查看；
- 导出时包含体系版本、全部来源链和优秀Mark。

在平台公共质量模型中，已发布“最佳整体标注”登记为 `AD_VIDEO` 金标准版本。金标准还必须记录专业域、原始答案来源、分歧、修订理由、适用置信度记录、审定人和内容哈希；这些新增质量信息不改变本文件的专业评分规则。
