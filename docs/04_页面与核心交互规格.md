# 页面与核心交互规格

文档版本：V0.6  
设计目标：像高品质视频网站一样简单、干净，以作品为中心；复杂能力只在用户主动进入作业或管理时出现。
适用专业域：`AD_VIDEO`

本文件描述广告视频专业域的专用体验，不是全平台所有专业域必须复用的页面模板。平台升格后，当前MVP仍直接进入视频首页，不显示空的专业域选择页。

## 2. 全局导航

内容首页不使用后台式左侧导航。桌面端顶部只保留：

- 品牌／站点标识，点击返回视频首页；
- 搜索；
- “全部、创意级别、标签”轻量筛选；
- 排行；
- 上传；
- 用户头像。

任务、我的作业、通知和管理入口收进用户菜单或个人页。部门标签不占用首页主视觉，只在个人信息、作者信息和筛选结果中按需出现。

Pad与手机采用相同信息层级：顶部品牌、搜索和用户入口；筛选使用横向滑动标签或底部抽屉。

普通用户始终围绕五个动作：看片、看脚本分析、练习交作业、搜索、评分。平时评分保持次要；只有评审会进行中，系统才把指定互评和轮次进度提升为显著任务。管理员切换到独立后台后，才出现导出、审核校订、统计、评选活动和数据管理。

## 3. 核心页面

### 3.1 视频首页／作品展台

#### 目标

打开网站首先看到作品，而不是任务统计和管理面板。整体感受接近电影网站、广告奖作品墙或Apple式视频展示页。

#### 内容

- 大幅、清晰的16:9视频封面；
- 标题；
- 当前创意奖级；
- 创意综合分和有效票数；
- 1–3个关键标签；
- “脚本及创意分析”；
- “作业／逆向脚本”。

提交人、部门、处理状态、作业数量等次要信息不在卡片正面堆叠，放入详情或轻量辅助信息。

#### 桌面结构示意

```text
┌──────────────────────────────────────────────────────────────┐
│ 站点标识     搜索作品或标签       全部／奖级／标签    排行  头像 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │   16:9 视频   │  │   16:9 视频   │  │   16:9 视频   │       │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
│  作品标题          作品标题          作品标题                  │
│  金奖级 84分 12票  银奖级 72分 8票   待评选 2票                │
│  脚本及创意分析    脚本及创意分析    脚本及创意分析            │
│  作业／逆向脚本    作业／逆向脚本    作业／逆向脚本            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### 主要操作

- 点击封面直接播放；
- 点击“脚本及创意分析”查看该视频的公开脚本；
- 点击“作业／逆向脚本”开始或继续自己的作业；
- 投创意奖级；
- 按创意级别或标签筛选。

#### 空状态

- 没有作品：显示一个克制的“上传第一条作品”入口；
- 搜索无结果：保留搜索词，并提供清除级别和标签筛选；
- 视频尚无有效投票：显示“待评选”，不显示0分；
- 视频尚无公开脚本：显示“暂无公开分析”，同时保留“开始作业”。

### 3.2 视频卡片、播放与创意投票

#### 目标

让用户用最少操作完成观看、评价和进入脚本。

#### 列表卡片

- 卡片主体是视频封面，不使用大量边框和信息表格；
- 封面中央只在悬停或聚焦时出现播放按钮；
- 卡片下方第一行显示标题，第二行显示“创意奖级 · 综合分 · 票数”；
- “脚本及创意分析”和“作业／逆向脚本”作为两个明确的文字按钮；
- 标签默认最多显示3个，其余折叠。

#### 播放交互

- 点击封面后立即打开大尺寸播放器；
- 桌面端可使用沉浸式浮层或简洁详情页，手机端使用全宽播放器；
- 播放器下方只保留标题、创意奖级投票、标签、脚本入口和作业入口；
- 关闭播放器后回到原首页滚动位置；
- 播放错误时提供重新加载和下载原文件，不把转码信息暴露成复杂后台界面。

#### 脚本及创意分析

- 有已发布最佳整体标注时默认展示最佳整体标注；
- 没有最佳整体标注但有已发布共识时默认展示共识；
- 没有共识但有管理员精修版时默认展示精修版；
- 以上都没有时，展示已提交成员作业列表；
- 用户可以切换作者阅读已提交作业；
- 用户可以打开持续共创区补充镜头、字段或整体观点；
- 未提交草稿不出现在列表；
- 内容以排版良好的长文档呈现，视频滚动后可缩为悬浮小窗。

#### 作业／逆向脚本

- 用户首次点击时打开与当前视频绑定的空白作业页；
- 已有草稿时直接继续，不重复创建；
- 作业页是干净的纵向文档，视频保持可观看；
- 用户提交后，该修订进入“脚本及创意分析”的成员作业列表；
- 提交前草稿仅作者和管理员可见。

#### 创意奖级投票

可选级别只有：

1. 大奖级；
2. 金奖级；
3. 银奖级；
4. 铜奖级；
5. 入围级。

交互规则：

- 每名成员对每个视频只有一张有效票；
- 平时入口使用次要按钮或折叠控件，不抢占播放、分析和练习入口；
- 选中后立即显示自己的选择和团队统计；
- 改票覆盖当前有效选择，但保留历史审计；
- 大奖、金、银、铜、入围分别换算为100、80、60、40、20分；
- 创意综合分为全部有效票换算分的算术平均值；
- 综合分区间对应展示级别：90–100大奖级、80–89.99金奖级、60–79.99银奖级、40–59.99铜奖级、20–39.99入围级；
- 少于3张有效票显示“票数不足”，不进入正式排行榜；
- 排行先按综合分降序，同分按有效票数降序，再按最近有效投票时间排序。

创意综合分评价视频本身；作业100分评价某个人的分析质量，两者必须使用不同名称和视觉区域。

#### 搜索与排序

- 默认展示全部作品，不设置行业分类；
- 创意级别使用五个筛选标签；
- 标签支持输入搜索和多选；
- 文字搜索覆盖标题、品牌和标签；
- 标签来源包括案例标签和已公开分析中的A/B标签，重名标签去重；
- 排序仅保留最新、创意综合分和精选；
- 作品列表渐进加载，返回首页时恢复原滚动位置；
- 清除筛选后返回统一作品展台。

### 3.3 提交视频案例

#### 步骤一：上传文件

- 选择或拖入视频文件；
- 不设置业务层面的格式、大小和时长限制；
- 显示分片上传、续传和处理进度；
- 上传失败可以继续，不要求重新选择整个文件。

#### 步骤二：案例信息

- 标题；
- 原始文件名和来源说明；
- 品牌／发布方；
- 发布时间或年份；
- 提交原因；
- 所属训练任务；
- 版权／授权状态；
- 公司内部下载提示。

#### 步骤三：系统处理

1. 读取文件基础信息；
2. 执行安全扫描；
3. 计算文件指纹；
4. 检测重复；
5. 保存原文件；
6. 为浏览器不兼容格式生成播放副本；
7. 生成封面、时长等元数据。

#### 步骤四：重复处理

发现重复时提供：

- 加入现有案例，登记自己为贡献人；
- 确认确实是不同版本后新建案例；
- 取消提交。

不允许系统静默创建重复案例。

### 3.4 脚本分析／作业纵向单页

#### 核心原则

用户从首页进入“脚本及创意分析”或“作业／逆向脚本”后，不再为逐镜脚本、整体标注、他人作业和评分反复跳转页面。全部内容在同一个纵向长文档中排列。

同一内容结构支持四种模式：

- 公开脚本及创意分析阅读模式；
- 我的作业编辑模式；
- 他人作业阅读与批改模式；
- 管理员批阅与精修模式。

切换作业作者只替换页面内容，不离开案例上下文。

#### 页面纵向结构

```text
固定页头：返回视频首页／案例标题／作者／作业状态／版本／实时总分计数器
固定视频区或悬浮小窗
01 逐镜脚本还原（包含逐镜创意点评）
02 整体判断与全篇创意总结
03 创意构成 A1–A9
04 故事组织 B1–B10
05 完整度与提交
06 原位百分制批改（分值嵌在对应内容旁）
07 字段批注与讨论
08 历史版本／管理员精修／团队共识／共创／最佳整体标注
```

左侧或右侧提供固定页内目录：

- 当前区块高亮；
- 完成度；
- 每个区块得分；
- 已评分项数和未评分项数；
- 错误数量；
- 点击后平滑滚动到对应区块；
- 不触发新页面导航。

#### 顶部固定信息

- 视频标题、品牌、贡献人；
- 当前查看的作业作者；
- 企业微信部门标签；
- 作业修订号、体系版本；
- 草稿／已提交／精修／共识状态；
- 同行均分、管理员分和发布分；
- 切换其他成员作业；
- 收藏、推荐；普通成员不显示原片下载入口。

不能只展示一份“综合标签”而隐藏个人判断。

#### 视频区

- 播放／暂停；
- 倍速；
- 当前时间码；
- 快速记录当前时间；
- 上一镜头／下一镜头；
- 仅限公司内部在线播放；
- 页面向下滚动后切换为固定悬浮小窗；
- 进入作业填写、学习阅读、分析修订或批改模式后，播放器始终留在视线范围内；桌面端采用屏幕右下方的小型悬浮窗，窄屏缩小并尽量不遮挡主输入区；
- 播放副本处理失败时显示处理状态并提示联系管理员。

原视频替换：

- 原上传者在作品信息区看到“替换原视频”，其他普通成员不显示该入口；
- 重新选择本地视频、确认权利声明并查看上传进度；
- 新文件完整入库且视频记录更新成功后才切换播放器，失败时仍保留当前可播放文件；
- 替换不新建案例，不改变视频ID、标题、逐镜脚本、作业、评分和公开分析；
- 旧文件不再通过普通播放接口访问，其对象位置和替换前后信息写入审计记录，以便管理员恢复；
- 正式管理员代替换能力在角色权限系统接入后开放，演示版先执行原上传者权限。

#### 逐镜脚本

以“镜头组”为一级视觉单元，每个镜头组内以连续表格排列所属镜头。组标题、组边界和组内行必须清楚表达层级，禁止把所有镜头呈现为彼此孤立的同级卡片。

表头严格保持以下13列，不得为了压缩页面随意合并专业内容项：

1. 镜头组序号／名称；
2. 镜头序号；
3. 时间段；
4. 景别；
5. 机位／角度；
6. 镜头运动；
7. 画面内容（镜头故事）；
8. 对白；
9. 旁白；
10. 字幕／屏幕文案；
11. 声效；
12. 音乐；
13. 创意点评／标注依据。

第1列和第13列在同一镜头组内纵向合并。创意点评通常针对整个镜头组填写，不再为每个单镜头重复制造点评格；历史逐镜点评读取时按镜头组汇总展示，新编辑结果保存到该组首镜头的兼容字段，其他镜头保持空值。

列宽交互：

- 13列保持独立，用户可拖动任一表头右边界连续调整该列宽度；
- 每列设置最小宽度，允许压缩次要信息，但不能缩到无法辨认表头和输入内容；
- 双击单列边界恢复该列默认宽度，工具栏提供“恢复默认列宽”；
- 同一页面内的编辑表格和已提交作业表格使用一致列宽，调整后同步更新；
- 当前列宽偏好保存在本机浏览器，在后续阅读和作业页面复用；它不属于标注内容，不进入提交快照、评分或Excel导出。

高频操作：

- 在当前时间创建镜头；
- 新增、重命名和调整镜头组；
- 自动将上一镜头结束时间作为下一镜头开始时间；
- 在组内插入、复制、删除、排序镜头；
- 上下移动镜头组并自动维护全局镜头序号；
- 展开编辑长文本；
- 通过键盘切换单元格；
- 从字段依据跳转到镜头。

“创意总体评价”和“复盘小结”合并为单一的“全篇创意总结”。历史数据读取时兼容两个旧字段，新的编辑结果同步写入兼容字段，避免旧作业丢失。

#### 9＋10标注区

每个字段展示：

- 编码和名称；
- 回答的问题；
- 选择规则；
- 主／副／辅助选择控件；
- 结构补充；
- 标注依据；
- 相关镜头引用；
- 完成状态。

V0.2附表A和附表B中的预设词表直接进入作业页：

- 每项“我的判断”旁显示“V0.2预设选项”入口；
- 鼠标移入入口即显示该字段自己的选项，不把19项词表常驻铺满页面；
- 浮窗同时显示回答问题、选择规则、选项类别、选项值和解释；
- 点击预设值将其加入当前答案，再次点击可以取消；
- 所有字段保留自由文本输入，不因选择预设值而锁死；
- 每项均提供“其他”入口；附表已有自定义项时沿用原名，否则显示“其他（自主输入）”；
- 选择“其他”后光标回到答案输入区，由用户继续填写新内容；
- 预设值、自由输入和历史答案继续写入同一个V0.2字段答案，不改变已发布作业的数据结构。

A3 使用级联选择；A4 和 B2 在界面上并列提示差异，但分别保存。

#### 阅读与权限

- 草稿提交前仅作者和管理员可以查看；
- 已提交作业向全部公司成员公开；
- 普通成员只能编辑自己的作业；
- 他人作业中的字段旁直接显示“评分／批注”入口；
- 管理员进入精修模式后创建独立精修版；
- 页面始终提供“查看原稿”和“查看修改差异”。

#### 持续共创

每个镜头、A/B字段和整体分析区都提供轻量“补充共创”入口：

- 打开后先显示已有贡献时间线；
- 用户可以添加文字、候选标签、标注依据、时间码或镜头引用；
- 新贡献追加在时间线末尾，不覆盖当前展示答案；
- 作者修改自己的贡献时产生新修订；
- 管理员可以在贡献旁添加优秀Mark和原因；
- 被标记内容显示克制的优秀标识，但不改变原文；
- 用户可以查看该内容是否已被最佳整体标注采纳。

管理员组装最佳整体标注时，界面按镜头和字段显示可采纳来源。每一项支持：

- 采纳个人作业；
- 采纳共创贡献；
- 采纳管理员精修或共识；
- 管理员新增或校订；
- 查看来源和修改差异。

发布后，最佳整体标注成为视频“脚本及创意分析”的默认内容。

#### 原位百分制批改

评分不是独立页面，也不在作业顶部或底部重复显示一整张脱离内容的卷面。用户开启“原位批改”后，评分输入直接出现在所评内容旁：

- 逐镜脚本还原7项和镜头创意点评4项紧跟镜头组表格；
- 商业意图、创意母题、故事梗概、创意思维链和全篇创意总结分别在对应内容旁评分；
- A1–A9、B1–B10各自在字段内容旁评分；
- 页面顶部只保留悬浮总分、已评项和自动保存状态；
- 页面末尾只保留总体批语、讨论推荐和正式提交动作。

评分结构保持：

- 商业意图3分；
- 创意母题5分；
- 故事梗概4分；
- 创意思维链10分；
- 逐镜脚本还原35分，拆为5大类、7个评分位：10、10、10、1、1、1.5、1.5；
- A1–A9共9分、B1–B10共10分；
- 镜头创意点评20分，拆为4个五分项；
- 全篇创意总结4分；
- 19项标注依据显示为不计分、自愿填写；
- 各计分内容旁直接提供分值输入框、满分和评分指南；
- 已得分／满分；
- 扣分原因和批语；
- 推荐进入周／双周讨论；
- 单项评分约1秒后自动保存为临时批改；
- 提交正式评分。

页面固定区显示实时总分计数器，包括“当前分／100、已评分项、未评分项、输入错误”。单项分数变化后立即重算；未评分状态不能被当作0分。

#### 内容修订与发布

- 编辑任一镜头、核心判断或9＋10字段后，系统约1秒自动保存个人草稿，不为每个内容项增加“保存／修订”按钮；
- 已公开作业发生修改后，顶部统一显示“修订草稿已保存”，并只提供一个“发布本次修订”按钮；
- 自动保存不覆盖团队正在看的公开快照；发布本次修订后，作品页默认展示新快照，旧快照继续保留；
- 首次发布使用“发布作业”，后续使用“发布本次修订”，不再使用容易把草稿与公开版混淆的笼统“保存”按钮；
- 发布成功后用户留在当前页面，不强制返回作品页。

#### 评分指南

- 鼠标移入评分指南区域后立即显示该项标准；
- 鼠标移出后立即消失；
- 指南包含满分、评分档位、判断重点、必要示例和评分量表版本；
- 不保留点击锁定状态，鼠标移出后立即关闭；
- 浮层不能遮挡当前分值输入框和需要参照的作业内容。

#### 保存状态

明确显示：

- 正在保存；
- 已保存时间；
- 本地有未同步修改；
- 保存失败；
- 版本冲突。

### 3.5 提交确认

提交前分三类提示：

- 阻断错误：体系版本缺失、选项超限、非法时间码；
- 必填缺失：按照任务配置判定；
- 建议补充：镜头未覆盖、总结为空或内容过于简略。

用户确认后：

1. 生成快照；
2. 标注修订变为已提交；
3. 更新训练任务完成情况；
4. 将该修订加入公司成员可见的“脚本及创意分析”列表；
5. 开放正式同行评分；
6. 触发相关活动消息。

提交确认页必须提示“提交后修改将产生新修订”。

### 3.11 评选活动

#### 平时模式

- 评分不出现在首页主操作序列；
- 用户阅读某份已提交作业时，可以主动进入评分；
- 不使用强提醒要求用户平时不断评分；
- 自由评分仍进入该作业的日常同行均分，但不自动属于某次评审活动。

#### 管理员发起评审会

1. 勾选参与评审的已提交作业修订；
2. 冻结参会成员顺序；
3. 设置首轮和第二轮时间；
4. 确认首轮晋级线“严格大于80分”；
5. 设置第二轮每份候选目标评分人数，默认3人；
6. 选择评分量表版本；
7. 预览环形互评关系、无作业参与者和异常情况；
8. 发布活动。

#### 首轮环形互评

20人、20份作业的默认任务示意：

```text
2号 → 评1号作业
3号 → 评2号作业
……
20号 → 评19号作业
1号 → 评20号作业
```

交互：

- 评审会开始后，“我的”页和顶部轻量横幅显示“首轮指定互评”；
- 点击直接进入被分配作业和100分评分卷面；
- 显示当前轮次、截止时间和完成进度；
- 完成指定任务后显示“自由补评其他作业”；
- 作业少于参会人数时，多余人员直接看到自由补评列表；
- 自由补评列表排除本人作业和自己本轮已评作业；
- 同一轮对同一作业再次进入时继续原评分，不创建重复评分。

#### 首轮汇总和晋级

- 每份作业显示有效评分人数和加权综合分；
- MVP所有普通同行评分权重为1；
- 首轮使用未四舍五入综合分判断；
- 严格大于80分进入第二轮，80分不晋级；
- 晋级名单经管理员检查无效评分后确认；
- 未发布前，参与者只看到自己的完成状态，不提前看到实时排名。

#### 第二轮

- 系统优先将候选分配给未在首轮评过该候选的其他成员；
- 每份候选目标至少3名有效评分者；
- 完成指定任务后仍可自由补评；
- 第二轮候选显示为统一列表，不突出首轮作者排名；
- 第二轮截止后按综合分降序排列；
- 前两名获得当次最佳作业奖；
- 第二名边界同分时先比较有效评分人数，再比较中位数，仍相同则交管理员确认。

#### 管理员结果

活动总览显示：

- 首轮指定互评完成率；
- 自由补评次数；
- 各候选有效评分人数、权重合计和综合分；
- 首轮晋级数量；
- 第二轮评分覆盖率；
- 平均分、中位数、高低分、标准差和分布；
- 第二轮排名和前两名；
- 异常评分及处置记录。

管理员确认后发布晋级名单和最终获奖结果。

#### 数据导出

7. 确认并生成导出任务。

## 4. 关键交互原则

### 4.1 不隐藏版本

作业单页、比较、评分、精修、共识和导出都显示体系版本、作业修订号和评分量表版本。

### 4.2 不混淆四种指标

视频创意综合分、案例热度、个人作业分、共识一致度分别展示。

### 4.3 不让批改覆盖原文

普通成员的批改只能产生评分和批语。管理员校订必须生成精修版，任何人都不能物理覆盖原作者历史。

### 4.4 不让播放失败阻断数据

播放副本处理失败时提示联系管理员处理；普通成员仍不提供原片下载，既有案例、标注和评分继续可查看。

### 4.5 不将表格列直接等同于数据含义

前端按字段规则提供专用控件，后台按答案角色保存；Excel 只是导入导出视图。

### 4.6 首页保持极简

- 首页不出现逐镜表格、评分卷面、任务统计或管理配置；
- 默认不展示行业分类；
- 每张卡片只回答“这是什么、评价如何、点哪里观看或分析”；
- 次要元数据按需展开；
- 视觉使用中性色、大面积留白、统一16:9画面和克制动效；
- 借鉴高品质产品的简洁原则，不复制任何第三方网站的具体视觉资产。

### 4.7 响应式

| 设备 | 视频展台 | 播放 | 作业 |
|---|---|---|---|
| 桌面 | 自适应多列卡片，保持大画面 | 大型浮层或简洁详情 | 视频悬浮＋纵向长文档 |
| Pad | 2列为主 | 全宽播放器 | 单列文档＋小型悬浮播放器，页内目录可收起 |
| 手机 | 1列连续视频卡片 | 全宽或全屏播放 | 单列文档＋小型悬浮播放器，评分总分条保持固定 |

### 4.8 页面壳与专业域页面分离

- 登录、个人菜单、任务提醒、权限校验和管理入口属于平台公共页面壳；
- 视频首页、播放器、逐镜脚本、9＋10编辑器和视频创意投票属于 `AD_VIDEO` 专业页面；
- 公共页面壳向专业页面传入逆向对象、作业、用户权限和适用版本；
- 专业页面返回保存、提交、评审和答案定位事件，不要求公共页面理解镜头或A/B字段；
- MVP只有广告域，不增加专业域切换器，也不为未来地产域预留空白菜单；
- 后续专业域可以拥有完全不同的对象详情和答案编辑体验。

## 5. MVP实施优先顺序

不设置独立的阶段0高保真原型门槛。研发按照本交互规格直接实施，优先顺序为：

1. 极简视频首页、卡片和播放器；
2. “脚本及创意分析”阅读入口；
3. “作业／逆向脚本”空白页与纵向编辑；
4. 五档创意投票、综合分和级别／标签搜索；
5. 逐项作业打分、固定总分计数器和悬停即显的评分指南；
6. 视频、用户、公开作业和评论的全局搜索；
7. 首轮环形互评、自由补评、严格超过80分晋级、第二轮评分和前两名评奖；
8. 追加式共创、优秀Mark和最佳整体标注；
9. 管理员统计、质量审核和数据导出；
10. 多人比较、管理员精修与共识；
11. 我的学习档案、排行榜和其他管理能力。
