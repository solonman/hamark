# 24 · 创意思维链流程图｜实施规格 V0.1

- 日期：2026-10-08
- 状态：已冻结（项目负责人 2026-10-08 逐轮确认 demo 后批准实施）
- 交互 demo：`docs/demos/2026-10-08-创意思维链流程图demo.html`（打开即用，含三套底稿、深浅主题、编辑器全部操作）
- 适用页面：V1.9 二合一工作台（`V19StudioDocument`，含集成版与只读查看）、V0.4 只读成果页（`V04DetailClient`）

## 一、目标

视频案例逆向第一模块的「创意思维链」从一段纯文字改为**横向流程图**呈现，编辑方式改为**带项目符号的大纲**。思维链评的是推导顺序，图要一眼看出链路走向，同时允许每一步有分叉、允许一份分析里有多条思维链。

## 二、已冻结的口径

1. **数据不改结构**：仍是 `facts.creativeThinkingChain` 一段文字，不改契约、不迁移历史快照。版本快照、对比基版、集成版按处取最新与溯源、条目评论、外部 Agent 接口、必填校验全部照旧。
2. **不嵌开源脑图组件**：画法（下面第四节）没有现成组件；主题、交互、权限拦截要与全站一致；不新增依赖。
3. **逻辑**：
   - 可以有多条思维链：每条有一个中心；条与条之间**不连线**，上下排开，虚线隔开。
   - 中心下的**第一层节点是有先后的步骤**（主链），从中心起按书写顺序首尾相连。
   - 某个节点的**下级是它的并列分叉**（无先后），层数不限。
   - 界面用语一律叫「思维链」，不叫「树」（编辑器按钮「＋ 新思维链」，标签「思维链 1／2…」）。
4. **画法**：横向流程，蛇形折行，连线一笔到底；条目通栏。
5. **版面（方案 A）**：思维链通栏留在原位置；「故事参照类型、创意机制、创意手法」三张选项卡并成一行三栏；其余各行不动。
6. **撤销两层**：编辑器开着时撤编辑器自己的步骤；关上后整次修改算工作台顶栏撤销里的一步。

## 三、存储格式与解析

存成 Markdown 嵌套列表文字：

```
商业问题与洞察
  - 问题：如何打破传统时尚广告高冷、堆砌模特画报的冰冷感？
  - 品牌：Kate Spade
    - 理念：乐观、俏皮与“可及的奢华”
创意主张
  - 快乐并不遥远，只要放慢脚步，就能发现
```

- 写出（编辑器保存）：中心顶格、不加记号；下级 `- ` 开头，每深一级多两格缩进；空节点不写；每行首尾去空白。
- 读入：逐行，空行忽略；缩进比上一层深就是它的下级（Tab、全角空格记两格；跳级按「上一个更浅的行」挂靠）；行首的 `- `、`–`、`·`、`•`、`*`（后跟空白）只是记号，去掉。
- **旧写法兼容**：全文多于一行且没有任何一行有缩进（线上现有的「1）…5）」），视为一条思维链：默认中心（显示案例标题＋「创意思维链」，拿不到标题时只显示「创意思维链」），每行一步。一编辑就按新格式保存。
- 只有一行时，就是一个中心、没有步骤。
- 显示时：步骤文字开头若是与其序号相同的「n）」「n)」「n.」「n、」，去掉（序号圈已表达），库里原文不动。
- 节点文字「短标题：说明」（冒号前 1–16 字、不含句读）显示时短标题加粗。

## 四、阅读态：横向流程图

1. 每条思维链一块：中心（酸绿底块）是第 0 格，第 1、2、3…步依次往后排。
2. **列数与格宽自适应**：可用宽度先留出外侧 U 形弯 24px；按最窄 13.5em 算一行放几格（至少 1 格、至多等于格数）；再把这一行宽度平分给各格，单格最宽 30em。中心与步骤同宽。
3. **蛇形折行**：第 1、3、5…行从左往右，第 2、4…行从右往左；只有一列时都视为从左往右。
4. **连线一笔到底**（SVG，主色 `--v04-subject`，2px，实心三角箭头）：
   - 同一行相邻两格：直线箭头，方向随行。
   - 换行：从上一行最后一格的外侧（行末在右就走右侧，在左就走左侧）绕一个圆角 U 形弯，接进下一行第一格同一侧。
   - 连线接在步骤框（不含下面的分叉）的左右边上，高度对准框里第一行文字。
5. **步骤框**：带序号圈（1、2、3…），文字完整显示不截断，框按内容自然高度（不强行同行等高）。
6. **分叉画成图，不画成列表**：从步骤框底部、序号圈正下方伸出主干线，用圆角折线分到每个分叉；分叉是带细边框的小标签；分叉的下级从那个标签底下接着伸，颜色更浅、字更小。阅读态**没有项目符号**，与编辑态区分开。
7. 宽度变化（窗口、侧栏、预览框）时重新计算列数与连线；网格不得被上一次排好的格子撑宽（外层用 `minmax(0,1fr)`）。
8. 深浅两套主题只用 `--v04-*` 变量；不得出现横向溢出。
9. 空值显示「—」。

## 五、编辑态：项目符号大纲

### 5.1 进入与退出

- 可编辑时点图的任意空白处进入编辑（悬停显示「点空白处编辑大纲」）；与其他条目一样受 `readOnly`／`locked`／`onBeforeEdit` 约束（集成版非老孙点击被拦并提示）。
- 编辑区：左栏是工具栏＋大纲＋快捷键提示＋「存进库里的文字」（折叠），右栏是实时预览（宽度不足 820px 时上下排）。
- **点外面＝保存并收起**：焦点离开整个编辑区即提交。左栏里的空白处（工具栏、大纲、提示）点击不算点外面；**点右侧预览或两栏间隙算点外面**。
- `Esc`：有跨节点选择时只取消选择；否则放弃这次编辑（恢复打开前的文字）并收起。
- 提交时文字与打开前相同（按写出规则规范化后比较）则不产生修改。

### 5.2 大纲外观

- 每行一个节点：中心是小酸绿方块＋右侧「思维链 n」标签，条与条之间虚线隔开；第一层显示**顺序号**圆圈；第二层空心圆点；更深层灰色小点；竖线连到上级记号。
- 第一层占位提示「下一步」，更深层「分叉」，中心「这条思维链的中心」。

### 5.3 按键与工具栏

| 操作 | 行为 |
|---|---|
| 回车 | 在光标处拆成两个同级节点；在有下级的节点末尾回车＝新建它的第一个下级；在空节点上回车＝回到上一级 |
| Tab／Shift+Tab | 下一级／上一级，下级跟着一起移动；最多比上一行深一级 |
| 行首退格 | 空节点：删除，下级上提一级；非空且非中心：回到上一级；中心：与上一行合并 |
| Alt+Shift+↑↓ | 整枝（含下级）与同级相邻的一枝对调 |
| ↑／↓ | 光标在行首／行尾时跳到上一行末尾／下一行开头 |
| 粘贴多行文字 | 按缩进拆成节点，首行并入当前行光标处，相对层级保留 |
| 输入法组字中 | 回车、Tab 等一律不接管 |

工具栏：← 上一级、→ 下一级、↑ 上移、↓ 下移、＋ 新思维链、撤销、重做（按下不夺焦点）。

### 5.4 跨节点选择

- 一个节点里照常选文字。以下任一操作切换成**整节点选择**（选中行整体高亮，焦点落在大纲容器）：鼠标从一个节点拖到另一个节点；行首 Shift+↑ 或行尾 Shift+↓；Shift+点击另一个节点；整行文字已全选时再按 ⌘/Ctrl+A（选中全部）。
- 选区总是连同所选节点的下级一起算。
- 选中后：⌘/Ctrl+C／X 复制／剪切为带缩进的大纲文字；⌘/Ctrl+V 用剪贴板内容替换选区；退格／Delete 删除；Tab／Shift+Tab 整体调层级；Alt+Shift+↑↓ 整体移动（选区第一行须是选区里最浅的一层）；Shift+↑↓ 扩缩选区；↑↓ 或回车退出选择回到行内；工具栏按钮作用于整个选区。单击任一行退出选择。

### 5.5 撤销

- 编辑器开着时：⌘/Ctrl+Z 撤销、⌘/Ctrl+Shift+Z 或 Ctrl+Y 重做，以及工具栏按钮；撤的是编辑器自己的步骤——同一节点连续打字（停顿不超过 1.2 秒）合成一步，每个结构操作一步；最多 100 步；按键不外传给工作台。
- 关上编辑器后：整次修改作为一次 `onCommit`，在工作台顶栏撤销（`V04StudioClient.commitDraft`）里只占一步。

## 六、页面接线

1. `V19StudioDocument` 第一模块拆成四段 `readingCore`：商业意图｜故事梗概、创意母题｜张力按钮 → 创意思维链（通栏）→ 选项卡行（故事参照类型｜创意机制｜创意手法，三栏，窄屏一栏）→ 创意承重载体｜具体说明、创意成立契约。字段 id（导航锚点）、评论入口、基版对比、集成版锁定／来源／溯源与现在相同。
2. 基版对比：沿用「已修改｜基版：原文」，基版原文保留换行。
3. `V04DetailClient` 只读成果页：创意思维链改为同一个流程图，放在第一段四格之后、单独通栏。
4. 外部 Agent 接口说明（`lib/agent-api/guide.ts`）补一句：创意思维链是 Markdown 嵌套列表，顶格为中心、第一层为有先后的步骤、更深层为并列分叉。
5. 旧版 V0.4 工作台（`V04WorkspaceClient`，仅在 V1.9 开关关闭时使用）与 V0.2／V0.3 页面不改，仍按纯文字编辑同一字段。

## 七、不做

- 思维链之间的关系连线；在图上直接拖拽、增删节点；节点级的版本差异高亮。

## 八、验收清单

1. 纯函数单测：解析／写出往返一致；旧写法识别；跳级缩进；序号去重；列数与格宽；蛇形落位；连线路径；大纲各项操作（拆分、上下级、退格、整枝移动、粘贴、跨节点选择的复制／删除／调级／移动）。
2. `npm test`、`npm run lint`、`npm run build` 通过。
3. 本机浏览器：示例、长链、旧写法三类数据在 1440／1100／窄屏下无横向溢出，折行与连线正确；深浅主题；编辑器全部按键、跨节点选择、两层撤销、点预览退出、Esc；集成版非老孙点击被拦；只读成果页显示流程图。
4. 线上：确认部署提交 SHA，用只读方式打开一个已有案例核对显示；不对真实案例做写入型测试。
