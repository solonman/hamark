# 演示纵切版实现与验收记录

记录日期：2026-07-31  
版本：Demo Slice D0.1  
目标：拿到一个已经做出来的网站，用一支视频完整演示未来的使用方法。

## 1. 本轮交付范围

本轮交付只实现最短但真实的数据闭环：

```text
上传视频 → 进入片库 → 播放 → 开始练习
→ 保存个人草稿 → 提交不可变快照 → 作品页公开回看
```

已实现内容：

1. 极简视频网站式首页；
2. 直接上传本地视频文件；
3. 视频对象存储和网页播放；普通成员不提供原片下载；
4. 标题、品牌、说明和标签；
5. 个人作业长页面；
6. 镜头组表格、核心判断、逐镜脚本、A1–A9和B1–B10；
7. 标注依据可选且不计入必填完成数；
8. 约1秒自动保存、统一发布修订和乐观锁修订号；
9. 提交前完整性校验；
10. 不可变提交快照、内容哈希和审计记录；
11. 作品页公开展示每位作者的最新提交；
12. 首页片名、品牌、标签、作者基础搜索；
13. 响应式手机布局基础；
14. 删除数据的软删除字段和回收站语义基础；
15. 35项、合计100分的原位同行批改控件和评分指南；
16. 作业编辑和原位批改时始终可见的悬浮播放器；
17. 原上传者可替换误传的原视频，保留同一案例的脚本、作业、评分和分析；
18. 逐镜脚本13列支持拖动调宽、最小宽度保护、本机偏好保存和默认值恢复。

## 3. 本版刻意不做

- 企业微信OAuth和部门同步；
- 真实多人身份和角色后台；
- 作业100分原位互评与悬停即显评分指南；
- 评选活动、环形分配和第二轮晋级；
- 管理员精修、优秀Mark、金标准和Excel导出；
- 分块续传、病毒扫描、视频探测和转码；
- AI自动拆解；
- 第二专业域的具体标注字段。

## 4. 下一阶段进入条件

1. 接入企业微信身份，建立真实个人数据隔离；

3. 建立作业评分、互评分配和评选活动；
4. 增加管理员精修、审计查看和Excel导出；
