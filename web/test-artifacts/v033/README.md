# V0.3.3 本机真实浏览器验收证据

验收日期：2026-08-12

环境：本机生产构建，`LOCAL_DEMO_ACCEPTANCE_MODE=1`，隔离的 `TEST_ONLY` 夹具

视口：桌面 1440×900、1280×720；窄屏 430×900

## 已跑通的业务闭环

1. 作者基于活动标准版 R2 建立作业、提交 V3。
2. 终审者建立批注，并分别执行整项替换、选区替换、插入、删除四类文本修订。
3. 终审者执行路径联合修订，将作业退回；作者处理批注、补充内容并提交 V4。
4. 批注状态依次验证：作者已处理、终审解决、重新打开、再次解决。
5. 终审者将“全片形成方式”改为“关键局部触发”但不关联桥段；批准被整案结构校验阻止，页面显示 `structure:formation-related-groups`。
6. 补齐关联桥段后批准成功，生成活动标准版 R3；R2、R1 保留为历史标准版。
7. 活动标准版与公开作业分离；历史正文在用户点击“按需读取历史正文”后才载入。
8. 活动标准版修订历史显示轮次、变更组、修订前后值、原因和终审结论。
9. 430px 窄屏下复验作品阅读页与作者作业页，悬浮播放器和核心入口均可用。
