# 专业逆向标注与能力训练平台

本项目用于建设“一套专业逆向标注与能力训练平台的公共底座＋可独立演进的专业域”。

广告视频创意是首个专业域。当前MVP仍聚焦以优秀视频作品为训练素材的“视频创意反写／逆向工程协作系统”；未来可以接入地产策略报告等其他专业域，但不在当前阶段预设其标注字段。

当前广告视频专业域同时是：

1. 个人创意能力训练网站；
2. 团队优秀视频案例库；
3. 多人反写、结构化标注、百分制批改和共识的数据平台。

## 当前可运行版本

网站工程位于 [`web`](web)。本机运行：

```bash
cd web
npm install
npm run dev
```

浏览器访问 `http://localhost:3000/`。

当前版本已经走通：

1. 上传本地视频并进入统一片库；
2. 网页播放视频；普通成员界面不提供原片下载；
3. 在一个纵向长页面填写个人逆向作业；
4. 还原逐镜脚本，并完成V0.2的A1–A9、B1–B10；
5. 内容修改约1秒自动保存为个人草稿，通过单一“发布本次修订”动作生成不可覆盖的公开快照；
6. 其他成员在作品页查看已提交的脚本及创意分析；
7. 按镜头组表格阅读和填写逐镜脚本，并对作业进行百分制批改；
8. 原上传者替换误传原视频，同时保留案例ID及全部脚本、作业和评分；
9. 像Excel一样拖动逐镜表头调整13列宽度，并在本机保存阅读偏好。
10. 在每个具体内容格原位批注或修订；选中文字后可直接操作，历史作业保持不变，接受的修订只写入作者个人草稿并产生新修订号。

企业微信身份、评选活动、管理员精修／导出和AI拆解仍按阶段计划后续实施。

## 当前工作原则

- 使用“反写”或“逆向工程”，不使用“仿写”描述当前产品。
- 公共底座负责身份、作业、提交、评审、审定、版本、审计、金标准和导出交换；广告视频域负责视频、镜头、9＋10、专业评分和V0.2 Excel。
- 平台公共模块不得反向依赖视频、镜头、时间码或A/B字段。
- 采用“公共外壳＋专业域强类型数据”，不建设承载所有专业域的万能字段表。
- 所有标注必须绑定标注体系版本。
- 个人草稿、个人提交、AI建议和团队共识分别存储。
- 使用企业微信身份登录；首发只有一个公司空间，成员保留企微部门标签。
- 第一版以直接上传视频文件为主，暂不建设网址解析流程。
- 内部成员可以查看其他人已提交的作业、标签和评分，并相互批改。
- 管理员可以产生“精修版”，但原始个人提交和评分历史不可被物理覆盖。
- 作业采用新版百分制：商业意图3分、创意母题5分、故事梗概4分、创意思维链10分、逐镜脚本35分、A/B结构化标注19分、镜头创意点评20分、全篇总结4分。
- 19项标注依据不计分；评分控件嵌在对应内容旁，顶部只保留固定总分计数器，评分指南鼠标移入即显示、移出即消失。
- 案例阅读、反写、标注和评分尽量在一个纵向滚动页面完成。
- 首页采用极简视频网站式展台，所有作品统一陈列，不建设行业分类树。
- 视频创意采用“大奖级、金奖级、银奖级、铜奖级、入围级”五档投票；视频创意综合分与作业100分严格分开。
- 个人草稿提交前仅本人和管理员可见，提交后向公司全员公开。
- 普通用户界面只围绕看片、看分析、练习、搜索和评分；管理、统计和导出进入独立后台。
- 管理员可以勾选已提交作业发起评选活动，系统统计参与率、分数分布和高低排名。
- 管理员可以校订内容、处置无效评分并发布优质版本，但必须保留原始数据和审计记录。
- 平时评分是次要动作；创意评审会开启后，系统突出显示轮次、指定互评任务、自由补评和晋级结果。
- 首轮默认采用环形互评，严格超过80分进入第二轮；第二轮前两名获得当次最佳作业奖。
- 共创采用追加式贡献，任何成员可以继续补充标注；管理员可打优秀Mark并组装最终最佳整体标注。
- 删除默认进入回收站。
- 视频上传不设置业务层面的格式、大小和时长限制；普通成员只在站内播放，不提供原片下载入口；底层仍执行安全、兼容和稳定性保护。
- 只有管理员可以导出结构化标注、创意投票、作业评分、评审活动、共创、最佳整体标注和行为汇总等数据。
- 先完成多人学习、标注、百分制互评、精修和共识闭环，再开发 AI 自动拆解。
- 不设置独立的阶段0原型或真实作业试批门槛，规划确认后直接进入MVP实施。
